# My First Post

Hello to anyone reading this, or just myself. I made this website to document my journey in the realm of cybersecurity and just tinkering with computers. I hope to update this website often, and maybe get a cheap custom domain.

For now, I just need to update the website with some basics like linking my LinkedIn, maybe a resume, and getting a basic about me page setup. And just customizing this theme to my liking.

In the future, I would like to update this with some write-ups on how I complete certain tasks like home labs, TryHackMe rooms, CTFs, and any other tinkering. TryHackMe has an event called Advent of Cyber, where they have a new challenge to complete every day, so I think that is my best starting point.

I followed an amazing tutorial from [Cognizant Netcentric](https://www.youtube.com/watch?v=nTLzLhFG9mc) on how to get GitHub Pages up and running. I used [Hugo](https://gohugo.io/) and the [re-terminal](https://themes.gohugo.io/themes/hugo-theme-re-terminal/) theme for my website. I will continue to host on GitHub pages for the foreseeable future. Writing posts on Google Docs, exporting as Markdown and updating my GitHub is a simple enough workflow for now.
